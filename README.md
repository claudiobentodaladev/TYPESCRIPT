# 📘 TypeScript Exercises

This repository contains my **TypeScript exercises and practice projects**.  
The goal is to track my progress, study key concepts, and build a useful reference of examples for future use.

---

## 📂 Repository Structure
- Each folder corresponds to a specific exercise or practice project.  
- Inside each folder you will find:
  - The source code of the exercise
  - A small `README.md` (when necessary) explaining what was done

---

## 🚀 Technologies Used
- [TypeScript](https://www.typescriptlang.org/)  
- [JavaScript (ES6+)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)  
- [Node.js](https://nodejs.org/)  
- [ts-node](https://typestrong.org/ts-node/) (for running TypeScript directly)  

---

## 📌 Topics Covered
- Type Annotations  
- Interfaces and Types  
- Functions and Generics  
- Classes and Inheritance  
- Modules and Namespaces  
- Enums  
- Type Guards  
- Utility Types  
- Working with APIs and async/await  
- Best practices and project structure  

---

## 💻 How to Run the Exercises
```bash
# Clone the repository
git clone https://github.com/your-username/typescript-exercises.git

# Enter the exercise folder
cd typescript-exercises/exercise-name

# Install dependencies
npm install

# Compile TypeScript to JavaScript
npx tsc

# Run with ts-node
npx ts-node index.ts
